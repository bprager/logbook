# Logbook 1.2.2 Release

Date: 2026-05-21

Tag status: not tagged in this commit.

`1.2.2` is a patch release for the stable `1.2.x` line. It improves the
terminal watcher for recorder operations and tracks the small operator scripts
used on `mimir`.

## Highlights

- Added recorder mount status to `logbook watch --ui curses`.
- Added guarded one-key `[e] eject` in the local curses watcher. The command is
  visible only when the Sony recorder is mounted and no pipeline run is active.
- Kept remote API watcher sessions read-only; they do not expose recorder eject.
- Added tracked `scripts/eject-voice-recorder` and `scripts/watch` helpers.

## Operational Notes

`scripts/watch` runs the local live watcher from the repository root:

```bash
cd /Users/bernd/Projects/Logbook
PYTHONPATH=src .venv/bin/python -m logbook.cli watch --env .env
```

`scripts/eject-voice-recorder` exits cleanly with `not attached` when the Sony
recorder is not mounted and otherwise delegates to `diskutil eject`.
