# Logbook 1.0.1 Patch Release

Date prepared: 2026-05-05

Tag status: tagged and pushed as `v1.0.1` on 2026-05-05.

## Release Meaning

`1.0.1` is a patch release for the stable operational `1.0.x` line. It does not change the
public ledger, Obsidian path, retention, or API contracts. It hardens live mount-triggered ingest
after the May 5 recorder recovery and documents the operational lessons learned.

## What Changed

- The StartOnMount LaunchAgent now runs `logbook process-mounted-recorder --env .env` instead of
  the read-only `recorder-discover` command.
- `process-mounted-recorder` performs the bounded production pipeline: copy/dedupe, live `odin`
  transcription, meeting diarization, Obsidian routing, pushed-vault sync marking, and Memgraph
  proof-graph sync.
- Recorder permission denials are reported as actionable command failures instead of Python
  tracebacks.
- The live `odin` HTTP client timeout is now long enough for real meeting audio.
- The `odin` worker normalizes MP3 audio to mono 16 kHz WAV before pyannote diarization.
- The vault workflow preserves dirty `.obsidian/workspace.json` state, creates generated-note roots
  before staging, and can resume by committing pending generated vault changes.
- The mounted-recorder processor recovers the clean-vault crash window by marking final pushed jobs
  as vault-synced even when no routing candidates remain.
- `lessons-learned.md` now records production incidents and prevention guidance.
