# Logbook 1.1.0 Release

Date: 2026-05-15

Tag status: not tagged in this commit.

`1.1.0` adds the independent pipeline observer/watch program and a versioned
developer quality gate. It remains on the stable operational line and keeps the
local-first recorder-to-Obsidian architecture unchanged.

## Highlights

- Added `GET /observer/snapshot` and `logbook watch` for read-only pipeline
  visibility.
- Added SQLite run/stage telemetry, active-run heartbeat reporting, stale-run
  detection, measured progress, historical ETA fallback, status filtering, JSON
  output, remote API snapshots, automatic day/night terminal appearance, and an
  optional full terminal dashboard with live key controls.
- Added bounded read-only Odin and Memgraph reachability probes in observer
  snapshots.
- Added a versioned `.githooks/pre-commit` hook backed by `scripts/quality-gate`.
- Added a dev dependency set for `coverage` and `diff-cover`.

## Quality Gate

Install once per clone:

```bash
git config core.hooksPath .githooks
.venv/bin/python -m pip install -e '.[dev]'
```

The gate runs:

```bash
.venv/bin/python -m ruff check .
npx --yes markdownlint-cli2@0.22.1 --config .markdownlint-cli2.yaml "**/*.md"
PYTHONPATH=src .venv/bin/python -m coverage run --branch -m unittest discover -s tests -v
.venv/bin/diff-cover coverage.xml --compare-branch=HEAD --fail-under=96 --include-untracked
```

The coverage threshold is a changed-line ratchet. The repository still prints
the full coverage report so older untested branches remain visible, but future
Python changes must carry at least 96% changed-line coverage.

## Verification

Release verification should include:

```bash
scripts/quality-gate
PYTHONPATH=src .venv/bin/python -m py_compile src/logbook/*.py
git diff --check
```
