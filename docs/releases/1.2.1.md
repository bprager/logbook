# Logbook 1.2.1 Release

Date: 2026-05-20

Tag status: not tagged in this commit.

`1.2.1` is a patch release for the stable `1.2.x` line. It fixes operator
visibility for recovered pipeline failures and updates live source-audio
retention to the approved one-week guarded cleanup policy.

## Highlights

- Fixed `logbook watch` so recent failed pipeline runs appear in the failures
  panel and failed count even when affected recording jobs later recover.
- Changed source-audio retention from 24 hours to one week (`168` hours) across
  runtime defaults, local configuration, documentation, and tests.
- Changed `local.logbook.retention-audit` from a read-only status job to an
  hourly guarded cleanup job:
  `cleanup-audio --env .env --execute --include-recorder`.
- Cleaned the currently eligible Sony recorder backlog through the audited
  gates. Jobs 45-90 now have local audio marked `trashed` and recorder audio
  marked `deleted`; jobs 91-108 remain retained until their one-week windows
  open.

## Operational Evidence

- Fresh cleanup dry-run reports `retention_hours=168`,
  `local_pending_count=0`, and `recorder_pending_count=0`.
- The Sony recorder now contains 18 known MP3 files, all already represented in
  the SQLite ledger.
- The reloaded `local.logbook.retention-audit` LaunchAgent points at guarded
  cleanup and exits successfully when kickstarted.
- OpenClaw runtime ownership remains unchanged; no OpenClaw services were
  started under `bernd`.
