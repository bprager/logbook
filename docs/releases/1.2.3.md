# Logbook 1.2.3 Release

Date: 2026-05-21

Tag status: not tagged in this commit.

`1.2.3` is a patch release for the stable `1.2.x` line. It hardens mounted
recorder ingestion against transient odin and vault workflow failures, and
includes the latest observer/watch refinements.

## Highlights

- Added bounded retries around mounted-recorder transcription and diarization.
- Made Obsidian CLI note writes verify target Markdown files and fall back to
  atomic filesystem writes when needed.
- Prevented historical vault-sync blockers from failing successful current
  mount ingestion runs.
- Added latest finished recording timestamp visibility to observer/watch
  surfaces.
- Updated the terminal watcher dashboard behavior and rendering.

## Operational Notes

The live mounted-recorder pipeline was recovered during this patch: jobs 109,
110, and 111 were processed and marked vault-synced, and a subsequent
`process-mounted-recorder --env .env` run exited cleanly with no new work.
