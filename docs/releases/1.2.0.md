# Logbook 1.2.0 Release

Date: 2026-05-17

Tag status: not tagged in this commit.

`1.2.0` promotes the modern observer surfaces from the post-`1.1.0` workstream:
a packaged web watcher, a full curses terminal dashboard, stronger quality-gate
coverage, and a clearer terminal quit affordance.

## Highlights

- Added `logbook watch-web`, serving a packaged React/Vite observer UI from
  FastAPI on loopback.
- Added shadcn-style local UI primitives, Lucide icons, compact progress and
  statistics panels, and automatic day/night appearance from local computer
  time.
- Added `logbook watch --ui curses` for a terminal-only dashboard with
  resize-safe panels, progress bars, status filters, and live key controls.
- Added an explicit `[q] quit` footer to the curses dashboard; pressing `q` or
  Escape exits cleanly with the current failure-policy exit code.
- Added `mypy` to the quality gate, included the watcher web production build
  in the hook, and raised the changed-line coverage threshold to 97%.
- Hardened the web root with a server-rendered observer snapshot fallback so a
  browser that blocks JavaScript still shows useful status instead of a loading
  card.
- Fixed dead-letter assignment to the log route so the obsolete generated
  dead-letter note is removed after the replacement log inbox note is written
  and audited.

## Verification

Release verification:

```bash
scripts/quality-gate
PYTHONPATH=src .venv/bin/python -m logbook.cli watch --env .env --once --ui curses
PYTHONPATH=src .venv/bin/python -m logbook.cli watch-web --env .env
```

The quality gate runs Ruff, mypy, markdownlint-cli2, the watcher web production
build, the full unittest suite under coverage, and diff-cover with a 97%
changed-line coverage threshold.
