# Logbook 1.0.0 Release

Date prepared: 2026-05-05

Tag status: tagged and pushed as `v1.0.0` on 2026-05-05 after explicit operator approval.

## Release Meaning

`1.0.0` marks Logbook as a stable operational release. The core CLI commands, bounded HTTP API,
SQLite-ledger processing model, Obsidian path contracts, retention gates, and Memgraph proof graph
are now treated as stable release surfaces. Future breaking changes should be called out explicitly
with migrations or operator steps.

## Operational Scope

- Live Sony ICD-PX370 ingest on `mimir`.
- Live `odin` ASR worker at `http://192.168.1.3:8765` using faster-whisper `large-v3`, CUDA, and
  `float16`.
- Live meeting diarization with `pyannote/speaker-diarization-community-1` after account-level gated
  model approval.
- Real Obsidian vault workflow for generated inbox notes, canonical daily logs, dead letters,
  category/meeting notes, review artifacts, and entity-linked daily logs.
- One canonical final daily log path per date, with late arrivals rebuilt atomically from ledger
  state.
- 24-hour source-audio retention gates for local copied audio and recorder-side audio. This historical policy is superseded by the one-week gate in `1.2.1`.
- OpenClaw-safe loopback status/action API on `127.0.0.1:8788`.
- Launchd rollout for the Logbook API, recorder mount probe, retention audit, and daily entity
  linker.
- Prometheus text metrics for the Logbook API and `odin` worker.
- Proof-carrying Memgraph memory graph sync, query, health, action resolution, and repair commands.
- Dry-run-first dead-letter management and `saga` backup/restore-drill commands.
- SOPS/age encrypted `secrets.yaml` tracked in the repo by operator request.
